# Banking System in C++

A Banking Management System developed in C++ using Object-Oriented Programming concepts and file handling.

## Features

- Create New Account
- Deposit Money
- Withdraw Money
- Check Balance
- View All Accounts
- Search Account by Account Number
- Delete Account
- Data stored using file handling

## Technologies Used

- C++
- OOP Concepts
- File Handling
- VS Code
- GCC Compiler

## How to Run

1. Compile the program:

```bash
g++ banking_system.cpp -o bank.exe
```
2. Run the program:


```bash
./bank.exe
```
